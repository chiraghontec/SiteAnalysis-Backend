## KGIS API Endpoints

- **Get administrative hierarchy**  
`POST http://127.0.0.1:8000/api/kgis/admin-hierarchy`  

- **Lookup district name**  
`POST http://127.0.0.1:8000/api/kgis/district-name`  

- **Get location details**  
`POST http://127.0.0.1:8000/api/kgis/location-details`  

- **Get Hobli code**  
`POST http://127.0.0.1:8000/api/kgis/hobli-code`  

- **Get Taluk code**  
`POST http://127.0.0.1:8000/api/kgis/taluk-code`  

- **Get distance between pin codes**  
`POST http://127.0.0.1:8000/api/kgis/distance-btw-pincodes`  

- **Get nearby administrative hierarchy**  
`POST http://127.0.0.1:8000/api/kgis/nearby-hierarchy`  

- **Calculate geometric polygon area**  
`POST http://127.0.0.1:8000/api/kgis/geo-polygon-area`
